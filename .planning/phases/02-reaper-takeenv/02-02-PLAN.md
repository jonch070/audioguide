Purpose: Allow users to configure ADSR-style envelope points for each item's gain automation, creating smooth gain transitions rather than static values.
</objective>

<tasks>

<task type="auto">
  <name>Add TAKEENV_ASR config options</name>
  <files>audioguide/defaults.py</files>
  <action>
Add three new configuration options for ASR envelope:
- TAKEENV_ASR_ATTACK: Attack time in seconds (default 0.0 - instant)
- TAKEENV_ASR_SUSTAIN: Sustain level as ratio 0-1 (default 1.0 - full gain)
- TAKEENV_ASR_RELEASE: Release time in seconds (default 0.0 - instant)

Add near other TAKEENV options (around line 86). Register in tests.py.
  </action>
  <verify>grep "TAKEENV_ASR" audioguide/defaults.py returns all three options</verify>
  <done>Three ASR config options exist with sensible defaults</done>
</task>

<task type="auto">
  <name>Implement ASR envelope generation in takeenv_processor</name>
  <files>audioguide/takeenv_processor.py</files>
  <action>
Modify add_static_takeenv() to accept optional ASR parameters. Generate envelope points:
- Point 1: start_time, 0.0 (silence at attack start)
- Point 2: start_time + attack_time, sustain_level (attack reaches sustain)
- Point 3: end_time - release_time, sustain_level (release starts)  
- Point 4: end_time, 0.0 (release ends at silence)

This creates an ASR (attack-sustain-release) envelope. If attack=0 and release=0, behaves like flat envelope (current behavior).

Add parameters: attack=0.0, sustain=1.0, release=0.0 to add_static_takeenv().
  </action>
  <verify>Call add_static_takeenv with attack=0.1, sustain=0.5, release=0.2 and verify envelope has 4 points</verify>
  <done>ASR envelope points generated correctly based on config</done>
</task>
