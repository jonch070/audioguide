<objective>

Purpose: Verify that VOLENV (track-level) and TAKEENV (item-level) can coexist without interfering, allowing users to control overall track volume separate from individual item volumes.
</objective>

<task type="auto">
  <name>Verify VOLENV and TAKEENV independence</name>
  <files>audioguide/fileoutput/reaper.py</files>
  <action>
In the write() method, ensure that when both enable_volumeenv AND TAKEENV are active:
1. VOLENV is written at track level (already works)
2. TAKEENV is written at item level (added in plan 02-01)
3. The volume calculations don't double-apply gain

The key issue: Currently when enable_volumeenv=True, the code extracts static gain from gain_envelope and applies it to VOLPAN (lines 111-116). This could conflict with TAKEENV. Modify to:
- If TAKEENV is being written, do NOT extract static gain for VOLPAN (let TAKEENV handle item gain)
- If only VOLENV (no TAKEENV), keep current behavior

Check: Is there an enable_takeenv parameter passed to write()? If not, add it and use it to determine whether to skip VOLPAN gain extraction.
  </action>
  <verify>Generate RPP with both VOLENV and TAKEENV enabled, verify both chunks exist and volumes are correct</verify>
