  <action>
Add granular synthesis options to defaults.py:

1. GRANULAR_ENABLE (bool): Enable granular synthesis mode
2. GRANULAR_GRAIN_SIZE_MS (float): Grain size in milliseconds (default 50ms)
3. GRANULAR_OVERLAP (float): Overlap ratio 0-1 (default 0.5)
4. GRANULAR_PITCH_VARIANCE (float): Pitch variance factor (default 0.0)
5. GRANULAR_AMPLITUDE_VARIANCE (float): Amplitude variance factor (default 0.1)
6. GRANULAR_POSITION_VARIANCE (float): Position variance within segment (default 0.0)
7. GRANULAR_HOP_SIZE_MS (float): Hop between grains (default grain_size * (1-overlap))

8. Add phase-coherent options:
9. PHASE_COHERENT (bool): Enable phase-coherent synthesis
10. PHASE_CORRECTION_METHOD: 'none', 'unwrap', 'predict'
</action>

Create audioguide/granular.py with:

   - Handles grain positioning within segment

   - Adjust grain size for frequency content
